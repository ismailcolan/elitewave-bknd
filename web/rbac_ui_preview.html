Database structure (plan)

Implementation uses these tables only — no RBAC logic in this HTML file.

ew_app_role

  • PK: role_code (SA, AD, EX, DR, CL)
  • role_name, status, sort_order

ew_app_module

  • PK: module_code
  • Sidebar rail: dashboard, consignment, invoice…

ew_app_screen

  • PK: screen_code (= page_script)
  • FK: module_code
  • screen_label, show_in_menu, page_script

ew_role_permission

  • PK: (role_code, module_code)
  • can_view/create/edit/delete — module defaults

ew_role_screen_permission

  • PK: (role_code, screen_code)
  • use_module_default (1 = inherit module row)
  • Optional can_* overrides

ew_super_page

  • PK: page_script
  • SA only: backup, role_permissions.php

users.role → load permissions on login. Effective screen access = screen override if use_module_default=0, else module row.
